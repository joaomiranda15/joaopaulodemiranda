# 🧓 Dia Nacional de Combate à Violência Contra a Pessoa Idosa

> Projeto universitário desenvolvido para a disciplina de Desenvolvimento Front End na **Universidade Católica de Brasília (UCB)**.

---

## 📖 Sobre o Projeto

Este é um **site informativo e educativo** criado com o objetivo de conscientizar a população sobre a violência contra a pessoa idosa, em alusão ao **Dia Nacional de Conscientização da Violência Contra a Pessoa Idosa**, celebrado em **15 de junho** — data instituída pela ONU em 2006.

O site aborda um tema considerado tabu na sociedade atual: os diversos tipos de abusos sofridos pelos idosos, como e onde denunciá-los, e como preveni-los. O tema ganhou ainda mais relevância ao ser escolhido como pauta do ENEM 2025.

---

## 📄 Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| 🏠 Home | [`index.html`](index.html) | Apresentação do tema e contextualização histórica |
| ⚠️ Tipos de Violência | [`tipos.html`](tipos.html) | Detalhamento dos tipos de violência (física, psicológica, financeira, etc.) com dados do Disque 100 |
| 🛡️ Prevenção e Combate | [`prevencao.html`](prevencao.html) | Como prevenir abusos e quais canais de denúncia utilizar |

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estrutura semântica das páginas
- **CSS3** — Estilização, animações de hover e layout responsivo com Grid e Flexbox
- **JavaScript (Vanilla)** — Menu hambúrguer para dispositivos móveis

---

## ✨ Funcionalidades

- 🎬 **Vídeo de fundo** com overlay no header de todas as páginas
- 📱 **Design responsivo** — menu hambúrguer em telas mobile (≤ 768px)
- 🎨 **Paleta de cores consistente** via CSS Custom Properties (variáveis)
- 🔗 **Navegação entre páginas** com indicação da página ativa
- 📊 **Gráfico informativo** com dados reais do Disque 100 (fonte: Aptare 360)

## 📢 Canais de Denúncia

> Informações importantes destacadas no site:

- **Disque 100** — Central gratuita do Governo Federal, 24h por dia
- **190** — Polícia Militar, para emergências
- **Delegacias** — Para registro de boletim de ocorrência
- **Ministério Público** — Para providências legais cabíveis
